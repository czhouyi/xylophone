# xylophone

木琴简谱曲谱库 —— 一个纯静态站点（GitHub Pages），包含**曲谱列表**与**曲谱详情**，
支持在线渲染简谱、abcjs 合成音频试听，并带播放进度高亮。

## 设计原则

- **数据与页面分离**：曲谱 meta 放在 `docs/data/scores/index.json`，谱面是 `docs/data/scores/<曲谱ID>.jianpu`
  纯文本文件，页面不内嵌任何曲谱数据。
- **JS / CSS / HTML 分离**：页面只做结构，样式在 `docs/assets/css/`，逻辑在 `docs/assets/js/`（ES module）。
- **零构建、零依赖安装**：不需要打包工具，push 即可发布。
- **记谱格式沿用 [jianpu.space](https://jianpu.space) 的写法**：现成曲谱可以直接粘进来。

## 数据格式

只有两个数据源，都在 `docs/data/scores/` 下。

**`index.json` —— 所有曲谱的 meta（只有这一份，列表页和详情页都读它）**：

```jsonc
{
  "scores": [
    {
      "id": "little-star",                        // 必须与谱面文件名一致
      "title": "小星星",                          // 列表页与详情页标题
      "subtitle": "Twinkle Twinkle Little Star",  // 可选，副标题
      "artist": "",                                // 可选，演唱者（如「陈奕迅」）
      "composer": "莫扎特 改编",                   // 可选，曲作者
      "lyricist": "",                             // 可选，词作者
      "difficulty": "入门",                        // 可选
      "bpm": 0,                                   // 可选，默认播放速度；0 = 用缺省的 120
      "tags": ["儿歌"]                             // 可选，列表页标签
    }
  ]
}
```

`artist` / `composer` / `lyricist` 可以留空（写空串），但写了就必须是字符串。
`bpm` 是这首歌的默认播放速度（40~208），写 `0` 表示用缺省的 120；
详情页的速度滑块一打开就以它为起点。
署名按「唱：陈奕迅　曲：陈辉阳　词：林夕」拼，缺哪项就省哪项；只有曲作者时原样显示（「莫扎特 改编」）。
`node tools/build-index.mjs` 会补齐缺省字段、按标题排序，并检查它与谱面文件是否一一对应。

**`<曲谱ID>.jianpu` —— 单首曲谱的谱面**，就是一个纯文本文件，里面直接写简谱：

```
key(C)
1155|665-|4433|221-|
L:一闪一闪亮晶晶满天都是小星星
```

换行就是谱面上的一行，不用再写成 JSON 里的 `\n`。同一个 ID 的 meta 和谱面必须同时存在，
缺哪边自检都会报错，不会再出现「改了标题忘了改列表」这种重复维护。

### 只有一份谱：ABC 是运行时生成的

谱面既用来**看**也用来**听**：页面加载时由 `abc.js` 把它翻译成 abcjs
需要的 ABC 谱，再交给播放器。数据里不存第二份谱，所以不会出现「改了简谱忘了改 ABC」。

翻译规则：音级按调性转成音名、`'`/`,` 转成大小写与撇号、时值（含附点与延长）转成长度后缀、
`#`/`b`/`n` 转成临时记号（与调号一致时省略）、`0` 转成休止符 `z`。
延音（音高 `-`）转成 ABC 的 tie（`G- G`）。abcjs 的合成器会把 tie 合并成一个长音
（核对过它生成的 MIDI：`C2-C2|` 与 `C4|` 的 MIDI 完全一致，而 `C2 C2|` 不同），
所以听感就是真正的一个长音，而不是两个断开的音。

**拍号（`M:`）是反推出来的**（数每小节多少拍，取众数）。弱起、变拍子这类谱面反推会不准，
遇到时需要在谱面开头显式声明——目前支持的写法是 `meter(3/4)`。

## 简谱记谱速查（谱面文件）

写法沿用 [jianpu.space](https://jianpu.space)，可直接粘贴现成曲谱：

| 写法 | 含义 |
| --- | --- |
| `1` … `7` | 音高；`0` 为休止符 |
| `#1` / `b2` / `n3` | 升 / 降 / 还原（前缀，可叠写，如 `##1`） |
| `1'` / `1,` | 高八度 / 低八度（后缀，可叠写，如 `1''`） |
| `1_` / `1=` | 八分音符 / 十六分音符（后缀） |
| `1-` | 增时线：紧贴数字，延长一拍（多一个 `-` 就再多一拍） |
| `-` `-_` `-=` | 延音：`-` 独立成音符，延续前一个音；可带自己的时值后缀（裸 `-` 一拍、`-_` 半拍、`-=` 四分之一拍） |
| `1.` | 附点（最多两个） |
| `\|` `\|\|` `\|]` | 小节线 / 双纵线 / 终止线 |
| `L:歌词` | 歌词行，紧跟在它所属的乐谱行后面 |
| `/key(D)` | 调性，写在谱面开头 |
| `meter(3/4)` | 拍号，可选；不写就由小节拍数自动反推 |

其它约定：

- **源文件的换行不决定谱面断行**：页面按容器宽度把小节装进每一行（每行放整数个小节，
  单个小节比屏幕还宽时它自己占一行），窗口尺寸变了会重新折行。`L:` 行仍然必须紧跟
  在其所属乐谱行下面——它只用来把歌词对到音符上，不参与排版。
- **歌词按顺序全局铺开**：一个中文字对一个可唱音符（休止符 `0` 和延音 `-` 不占歌词位），
  不要求每行的字数刚好等于该行音符数——某行多出的字会顺延到下一行的音，少了就留空，
  所以写歌词不必精确到行。需要占位但不显示字时写 `_`；某个音符不填词时用 `*`；
  引号包起来的一整段算一个歌词位（如 `"(間奏)"`）。
- **标点不占音符位**：`，。！？` 这类标点会跟在它前面那个字后面一起显示，不会多出一个槽位，
  所以带标点的歌词可以直接粘。
- **速度不写在谱面里**：谱面开头只写调性（和可选的拍号）；播放速度由详情页工具栏上的「速度」滑块决定，
  默认 120。谱面里写了 `bpm` 也不生效，`node tools/check.mjs` 会直接报错。
- **延音横杠 `-` 有两种写法**（跟 jianpu.space 一致）：紧跟在数字后面是**增时线**（`5--` = 一个音 3 拍）；
  独立写出来就是一个**延音音符**，延续前一个音（`5 -` = 5 唱两拍），还能带自己的时值后缀
  （`-_` 半拍延音、`-=` 四分之一拍延音）。延音音符和休止符 `0` 一样不占歌词位。
- **认不出来的字符会被跳过**（不报错）：这样粘进来的谱面不会因为一两个怪字符就整行作废，
  但时值会悄悄少掉。详情页的「✎ 临时改谱」面板会把这类字符连行号一起提示出来。
- `node tools/check.mjs` 会校验歌词槽位与音符数是否逐行对齐。

## 播放与进度高亮

- 音频由 **abcjs** 合成，音色在下拉框里选（木琴 / 马林巴 / 颤音琴 / 钟琴 / 钢片琴 / 钢琴）。
- 速度用工具栏上的滑块调（40~208 BPM）：每首歌的默认速度由 `index.json` 的 `bpm` 决定
  （`0` 或没写就是 120），拖动时只更新读数，**松手后在下次播放时生效**。
  谱面上的进度高亮与音频用的是同一个速度，不会错位。
- 音色切换**在下次播放时生效**（切完会重新加载音色并回到开头）。
- **暂停后再点播放，从暂停处继续**，不会回到开头；「停止」才会回到开头。
- 每个音符在谱面上是三态之一：**已播放**（浅色底）、**正在播放**（高亮底 + 反白字）、**未播放**（无底）。
  进度位置由 `notation.js` 的时间轴按 `bpm` 与拍数换算，播放器只负责提供当前秒数。
  高亮以「一段延音」为单位：一个音连同紧跟它的那串 `-`（不管写成 `6---` 还是 `6 - - -`）
  共用一个块，播放时整段一起亮、整段一起变成已播放——简谱里那本来就是一个音。
  歌词则对准它唱的那个数字，不看这一段有多宽。
- 播到结尾会提示「播放完毕」并回到未播放状态；小节内连续的八分音符共用一条连在一起的减时线，跨小节会断开。

## 临时改谱（只在当前页面生效）

详情页下面有「✎ 临时改谱」：展开后直接改谱面，停手约 300ms 自动重新渲染，
并按新谱重新预加载音频，点「播放」就能试听改后的效果。

- **改动不落盘**：不写服务器、不写 localStorage，**刷新页面就回到仓库里的原谱**（也可以点「恢复原谱」）。
- 编辑时即时反馈解析结果：音符数、行数、调性，**每行歌词对不对得上**，以及
  **有没有认不出来、被静默跳过的字符**（会连行号一起说，例如「第 11 行『%』」）。
  这类字符不报错、也不会让谱面失效，但会让那一处白白少掉时值。
  歌词错位、或者一个音符都没解析出来时不会应用，页面保持上一版。
- 这是“试一下”的口子，不是编辑主力：想真正留下来，把文本粘回
  `docs/data/scores/<曲谱ID>.jianpu` 提交。

## 新增一首曲谱

1. 在 `docs/data/scores/` 新建 `<曲谱ID>.jianpu`（ID 用小写字母数字与连字符，如 `happy-birthday`），
   把简谱原样粘进去——换行就是谱面上的一行，格式见上面的速查表。
2. 在 `docs/data/scores/index.json` 的 `scores` 里加一条同 `id` 的 meta（标题、词曲作者等）。
3. 整理索引并自检：

   ```bash
   node tools/build-index.mjs
   node tools/check.mjs
   ```

4. 本地预览确认后提交推送。曲谱详情链接形如 `score.html?id=happy-birthday`。

## 自检

```bash
node tools/check.mjs
```

会检查这些事（任一失败即退出码非 0）：

- `index.json` 可解析、没有 BOM / 乱码、必填字段齐全（含 `artist` / `composer` / `lyricist`）、`id` 不重复；
- `index.json` 与 `<曲谱ID>.jianpu` 谱面文件双向一致（有 meta 没谱面、有谱面没 meta 都会报）；
- 简谱能解析出音符、歌词与音符总数对得上、谱面里不写速度、占位符（`_` / `*`）未漏进谱面；
- 延音横杠 `-` 的两种写法都解析正确（增时线算拍、独立的 `-` 延续前一个音且不占歌词位），
  生成的 ABC 用 tie 表达且音符数不变；
- 真正认不出的字符会被解析器记下来并报出行号，临时改谱面板据此提示；
- 由简谱生成的 ABC 音符数一致、头部字段（`M:` / `L:` / `Q:` / `K:`）完整；
- 渲染出的音符节点数与解析结果一致、序号连续、小节线数量正确；
- 排版按容器宽度折行：每行装整数个小节、不超过容器宽度，窄屏比宽屏排更多行；
- 播放进度三态在起点 / 跨音 / 播完 / 时间回退 / 未播放时都正确，且一段延音（`6 - - -`）整段一起亮；
- 音色编号解析正确（钢琴是 GM 0，不能被当成空值吞掉），下拉默认项与代码默认一致；
- HTML 引用的本地资源都存在、JS 用到的 DOM id 都存在；
- 起临时服务器逐个 URL 探活（页面 / 样式 / 脚本 / 数据 / 404）。

## 本地预览

页面用 `fetch` 读取 `index.json` 和 `.jianpu` 谱面，**不能直接双击 HTML 打开**（`file://` 会被浏览器拦截），
需要起一个静态服务器：

```bash
npx serve docs          # 或： python -m http.server 8000 -d docs
```

## 部署到 GitHub Pages

仓库 → **Settings → Pages**：

- **Source** 选 `Deploy from a branch`
- **Branch** 选 `main`，目录选 **`/docs`**，保存

稍等片刻站点即可访问：

```
https://czhouyi.github.io/xylophone/
```

之后每次往 `main` 推送，Pages 会自动重新发布。

## 第三方依赖（CDN 引入，无需安装）

- [abcjs](https://abcjs.net/) — 音频合成；音色使用 FluidR3_GM 音色库

简谱渲染是本站自研的（`docs/assets/js/notation.js`），不依赖任何外部简谱库。
